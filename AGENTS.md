Read [README.md](README.md) for the project index and [SPEC.md](SPEC.md) for the
normative corpus contract. This is the public documentation hub, not pipeline code.

- Inspect Git status/diff; preserve existing edits and stage named files only.
  Preserve the human commit author and use English technical documentation.
- Specification changes affect producers, corpora and consumers. Do not change
  paths, field meanings or history requirements as incidental editorial cleanup.
  Review conformance and migration implications before changing the contract.
- Link to authoritative coverage rather than copying changing counts into prose.
- Do not include private service implementation, credentials or operational notes.
- For documentation changes validate relative links and example syntax; there is
  no root application build to run. Inspect workflows before publishing changes.
